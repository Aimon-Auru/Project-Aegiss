# AEGIS 0.8.0 — picture guides and offline world overview

Install **AEGIS-illustrated-S25-0.8.0.apk over your existing AEGIS without uninstalling**. It uses the same application ID and development signer, versionCode6. Existing vault records, settings, guides and bookmarks are retained; no destructive database reset is introduced. Keep your separately retained recovery key for any existing backup. Do not downgrade.

Open **Library → Ranger → Leave a useful trip plan**. You will see a detailed three-scene illustration, a completed fictional itinerary and a three-stage walkthrough. Choose **Enlarge illustration** to pinch/pan, zoom with the buttons or reset. Packing, conditions and offline-map preparation also have new detailed illustrations. The other map-reading guides include numerical diagrams and the original USGS north-reference picture. All eight guides work offline without AI or vault access.

The new pictures are labelled original AI-generated explanatory illustrations; they are not real routes, photographs, species identification or medically reviewed procedures. Numerical/trip examples are explicitly fictional examples, separate from live location data. Text retains its cited sources and general-reference review status.

The English illustrated pack is included automatically. **Library → Guide packs** shows real edition/file/payload sizes for English, Filipino and Czech. To update an installed optional language, download its **edition 2** file through your browser and import it in the app. Downloads use an external browser; already transferred pack files import offline. Each pack is about 15.3 MB because it now contains the actual artwork. Filipino/Czech are draft translations, not independently reviewed language packs; controls remain English.

Open **Home → Open offline world overview** for actual bundled country geography, with country lookup and pan/zoom. Natural Earth 5.1.2 provides a generalized 1:110 million world overview, approximately 85°S–85°N. **Detailed regional maps are not installed:** no streets, trails, topography, live location overlay or routes. Country boundaries can be disputed/outdated. This is independent of the separate foreground GPS/compass/track screen. A renderer failure should leave the back button available; this dataset's native rendering has not yet been tested on your S25.

The previous kit inventory, editable household checklists, encrypted notes/waypoints/backups, foreground GPS/compass/breadcrumbs/GPX and optional local guide assistant remain. See FIELDTOOLS-INSTALL.md and ASSISTANT-INSTALL.md for their workflows and limits. No repeat of the earlier feasibility benchmarks is required. The optional AI model is a separate 347.3 MB import, not included in this APK.

INTERNET remains absent. ACCESS_NETWORK_STATE is used for MapLibre initialization; it cannot authorize internet access. Location permissions are only used by the existing explicit-start GPS tool. No background/remote tracking, camera, microphone, nearby or broad storage permission is added.

This remains a development build. Current reviewed first aid/species-edibility libraries, detailed maps/routing, family communications, country/radio datasets, broader RAG and production security/hardware qualification are unfinished. General references and illustrative examples are not specialist approval. Private-data security acceptance on the actual device remains pending.

## First-aid illustrations from the original publisher

Open **Home → First aid: illustrated publisher handbook** or **Library → First aid → Open illustrated publisher reference**. The official European Resuscitation Council 2025 English handbook includes its own illustrations. **Download from ERC in browser** opens the publisher's original 17.4 MB PDF; save it while connected. **Open a saved PDF** opens your document picker and then your PDF viewer. Check the complete file opens after disconnecting. AEGIS does not copy, bundle or retain the PDF or file permission. A separate PDF viewer and a genuinely local saved copy are required for offline opening. This original publication is separate from AEGIS's still-unfinished clinically reviewed medical library and decision trees.

The launcher icon now uses your supplied logo's gold A, red/white compass needle and forest identity, simplified for small sizes. Android adaptive masking supports regular and round launcher shapes. Your launcher can briefly cache the previous icon after updating; reopen the app if needed. The main app label remains AEGIS.
