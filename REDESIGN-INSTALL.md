# AEGIS 0.9.0 — a simpler, clearer interface

Install **AEGIS-redesign-S25-0.9.0.apk over your existing AEGIS without uninstalling**. Your supplies, plans, places, notes, saved guides, language packs, imported AI file, shortcuts and appearance setting are retained. Do not downgrade.

The app has four main tabs:

- **Home:** First aid, Navigate, My kit and Ask AEGIS are large, clearly labelled cards. Explore guides opens the illustrated library.
- **Guides:** Search, browse picture cards and tap a bookmark to save a guide. The bookmark at the top opens saved guides. A guide's text size control is Aa; sources and review details are at the end of the guide.
- **Tools:** Location/compass, world map, kit/plans, first-aid handbook, assistant, private notes and guide downloads are listed together.
- **Settings:** Choose Light, Dark or Use phone setting. Privacy, backups, phone details and app information are here. Technical details no longer fill Home.

For the brighter appearance, choose **Settings → Appearance → Light**. Dark mode is also redesigned; your existing choice is preserved.

**My kit** unlocks with your phone's screen lock. Add a supply with its name, amount and unit. More details contains category, storage, priority, notes and dates; dates use a calendar. Plans, Places and Notes remain available. Backup/recovery and private-data security acceptance remain development work; use sample private records until qualified.

**Navigate** starts location only when you tap Find my location. The compass uses magnetic north. Walks clear when leaving this screen: save a walk first if you need its GPX file. Saving explicitly warns that the file contains unencrypted coordinates/times. Return to start sets a straight-line target and does not establish a safe route.

**First aid** offers Open saved handbook or Get the handbook. The ERC publication needs a saved local PDF and a separate viewer for offline opening; it is not AEGIS-reviewed in-app medical content. **World map** is still a coarse country overview, without detailed roads, trails or routes.

**Ask AEGIS** can find guides without a model. Offline assistant setup is optional; get the 347 MB file in your browser, then add it. Existing imported weights are retained. It suggests existing English references; it does not generate reviewed emergency or species advice.

**Guide downloads** shows real file sizes and language status. Get a pack through your browser, return and choose Add downloaded pack. English is included. Filipino and Czech are draft guide translations, not independently reviewed; app controls remain English. Existing edition-2 files still work.

The redesign adds no permissions or accounts and retains the no-INTERNET app. The master project's unfinished medical/species, detailed maps, country/radio, family coordination and production requirements are unchanged. Host checks are not physical S25, security, clinical or language approval.
